Sistema de Cadastro de Motores em Python

Documentação técnica do protótipo monolítico desenvolvido em memória utilizando apenas funções e listas (arrays).

Sobre o Desenvolvimento

Este projeto foi desenvolvido no CentroWEG, unidade do SENAI localizada dentro do parque fabril da WEG em Jaraguá do Sul (SC). O objetivo da atividade é praticar lógica de programação, validação de dados e manipulação de estruturas em memória antes da integração com bancos de dados.

Python 3 Estruturas em Memória Programação Procedural CentroWEG

Arquitetura do Código (cadastro_motores.py)

O programa opera de forma monolítica em um único arquivo, dispensando dependências externas ou banco de dados. Os registros são armazenados em uma lista global de dicionários (motores = []) com controle incremental de identificador (proximo_id).

cadastrar_motor()

Valida se o código já existe, verifica se potência (CV), tensão (V) e RPM são maiores que zero e adiciona o novo dicionário à lista.

listar_motores()

Retorna todos os motores armazenados atualmente no array em memória para consulta ou exibição.

buscar_motor(termo)

Realiza busca case-insensitive por ID exato ou correspondência parcial em código, modelo ou fabricante.

atualizar_status_motor()

Altera a situação operacional do equipamento entre os estados permitidos: ativo, manutencao ou inativo.

remover_motor(id)

Percorre o array com enumerate() e remove o registro correspondente utilizando pop().

menu_interativo()

Gerencia o loop de interface no terminal (CLI), capturando entradas do usuário e tratando erros de validação via try/except.

Modelo de Dados Utilizado

Cada motor cadastrado é representado como um objeto (dicionário Python) dentro da lista motores:

{
  "id": 1,
  "codigo": "MOT-001",
  "modelo": "W22 IR3",
  "fabricante": "WEG",
  "potencia_cv": 15.0,
  "tensao_v": 380,
  "rpm": 1760,
  "status": "ativo"
}
